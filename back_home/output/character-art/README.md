# Chet 人物立绘

使用内置 `image_gen` 为 20 位预设人物分别生成原创立绘，每位角色独立调用一次。整体采用精致国漫／韩漫半写实厚涂、细腻五官和戏剧光影，服装与场景按现有性格和兴趣设计。

- 应用图片：`assets/ai_characters/<character-id>.png`，1024 × 1536。
- 全部生成提示词与图片对应关系：`prompts.json`。
- 可点击放大的完整总览：`gallery.html`（直接在浏览器中打开）。
- 界面接入：AI 发现卡片、AI 好友列表、聊天页头像及资料头像。
- 已有账号按角色 ID 直接加载本地立绘，无需 Firestore 数据迁移；用户上传的图片优先显示，加载失败时回退到本地立绘。自定义角色继续使用上传图片或原有图标。
- 小尺寸头像按 256 像素宽解码，大立绘保留原始清晰度。
