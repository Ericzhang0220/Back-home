# 全局底部导航手势

- 从底部安全区域上滑，唤出 Room / Hall / Chat / Profile 导航卡片；首页、主页面及后续打开的详情、设置页面共用此行为。
- 在导航卡片上向下拖动即可隐藏，慢速拖动和快速下甩均可。
- Room 主视图之外，双击页面可唤出隐藏的导航。Room 内的双击继续用于房间视角、子视图和商店控件，不唤出底部导航；从 Room 打开的独立页面仍支持双击。
- 唤出后保留原有 4 秒自动隐藏。键盘打开时隐藏导航并暂停唤出手势；文字框双击选词继续交给输入控件处理。

`AppShell` 在内容 Navigator 外统一绘制导航，避免新页面覆盖它。页面内部继续用最近的 Navigator 打开子页面；切换导航标签会返回该 Navigator 的首页并切换标签。系统返回键交给 `NavigatorPopHandler` 处理。确认对话框保留根 Navigator 的模态行为。

`BottomNavigationReveal` 通过指针 Listener 观察手势，不抢占页面按钮、滚动和文字选中；多指操作、长按和拖动不作为双击。
